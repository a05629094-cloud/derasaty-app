تحديث تنسيق دراستي وإضافة إيموجي لكل مهمة

الملفات داخل هذا الضغط:
- mockup-style-v3.css: يجعل المواد والمهام في قائمة رأسية، والملف الشخصي مرتبًا تحت بعضه.
- task-emojis.js: يضيف اختيار إيموجي عند إضافة كل مهمة ويحفظه بجانب اسمها.

الخطوات:
1) فكّي ضغط هذا الملف.
2) في مستودع GitHub افتحي Add file ثم Upload files.
3) ارفعي mockup-style-v3.css و task-emojis.js معًا، ثم Commit changes.
4) افتحي index.html واضغطي Edit.
5) في سطر التنسيق الموجود حاليًا استبدلي v2 بهذا السطر:
<link rel="stylesheet" href="mockup-style-v3.css?v=3">
6) قرب نهاية الملف ابحثي عن:
<script src="page-navigation.js"></script>
وأضيفي تحته مباشرة:
<script src="task-emojis.js"></script>
7) اضغطي Commit changes.
8) افتحي الموقع واضغطي Ctrl + F5.

بعدها عند الضغط على «أضف مهمة» اختاري الإيموجي من القائمة، وسيظهر بجوار المهمة ويحفظ معها.
